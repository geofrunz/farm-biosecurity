CARICA QUI I TUOI JSON

Questa cartella è inizialmente senza scenari.

1. Usa il programma DOCENTE per creare e approvare un esercizio.
2. Salva il progetto approvato come file .json.
3. Su GitHub apri la cartella scenari, seleziona Add file > Upload files, carica il JSON e conferma con Commit changes.
4. Potrai aggiungere, sostituire o eliminare i file JSON quando vorrai.

Questo file .txt serve solo per rendere visibile la cartella nel repository; non compare fra gli esercizi degli studenti.
